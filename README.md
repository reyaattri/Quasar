### Learn it once. Remember it longer.

Quasar is a visual memory-learning app that gives every hard idea a place to live: a room, a character, a strange little story you can walk back through. It doesn't stop at showing you the idea once. It asks you to recall it without help, explain it in your own words, and then use it on a problem you haven't seen before. That's the whole loop, repeated across every subject in the app.

It's built with Expo and React Native, so the same codebase runs on iOS, Android and the web. The source is public here under the MIT license, and this is my entry for the RevenueCat Shipaton 2026 Next Gen Award. You can try it right now in the browser at [quasar-memory-garden.reyaattri4.chatgpt.site](https://quasar-memory-garden.reyaattri4.chatgpt.site/), no account needed.

## What's inside

The centerpiece is Cell City, a six-episode biology story where you solve a city-wide blackout by learning how a real cell actually makes energy. You walk an illustrated atlas of six districts, meet a cast of characters who react to every answer you give, and connect each piece of real biology (glycolysis, the citric acid cycle, ATP synthase) to its place in the city before the story moves on. Alongside it, a memory toolkit teaches the underlying techniques, memory palaces, number pegs, the Major System, through short illustrated conversations, and full courses cover SAT vocabulary, biology, calculus, the digits of π, and Korean, where a Hangul Lab and a sentence trail take you from building syllables to six everyday expressions.

Your own material fits in too. Notes → Quiz turns anything you paste or upload into highlighted study sections and flashcards first, then a quiz that comes back later for spaced review, built entirely on your device. Every day, the Today plan looks at what you're closest to forgetting, what's due, and how far off your exam is, and fits a session into 5, 15 or 30 minutes. When you're ready to prove you actually understand something, Teach-Back hides the lesson while you explain it back, the Why Ladder asks questions until it finds exactly where your understanding breaks, and Case Lab hands you a problem you've never seen and asks you to use the idea on it.

Mistakes aren't just marked wrong and forgotten. Error Memory names the specific wrong answer you keep choosing and keeps offering new angles until you get it right on your own, with no hints counted as mastery. Progress itself is tracked honestly: Ready and the Memory Garden measure recall, understanding and application as three separate things, and an idea only blooms once you've answered it correctly, unaided, on two different days. Spaced review throughout the app runs on [FSRS](https://github.com/open-spaced-repetition/ts-fsrs), the same scheduling algorithm used by serious flashcard tools.

Quasar Plus is currently open access, every one of its AI features works for free while the app is in this launch window. Normally it would sit behind a RevenueCat subscription; when that's switched back on, it adds an AI tutor that reads your explanations, AI-written quizzes generated from your own notes or PDFs, personalized versions of the vocabulary stories, and fresh memory hooks written specifically for a mistake you keep making, all generated by Claude on the server.

## Run it

You'll need Node.js 22 or newer. The lessons, artwork and learning loop all work with no keys and no account.

```bash
git clone https://github.com/reyaattri/Quasar.git
cd Quasar
npm ci
npm run web
```

`npm start` opens the same app in Expo for iOS and Android. Setting up the optional services, Supabase, RevenueCat and Anthropic, is covered in `docs/SETUP.md`.

## Tests

```bash
npm run typecheck
npm test
npm run test:e2e
```

The unit tests cover the planner, spaced review, Error Memory, the notes quiz, Cell City, Hangul and the database rules. The browser tests walk through the app's main flows at phone size.

## Project structure

| Path | What's there |
| --- | --- |
| `App.tsx` | App shell, onboarding, navigation and purchases |
| `src/features/` | Cell City, the courses, Notes → Quiz, Teach-Back, Why Ladder, Case Lab, Today, Error Memory, Ready and the Memory Garden |
| `src/lib/` | Progress, spaced review, the planner and the AI client |
| `src/data/` | Lesson content, Cell City episodes and memory cues |
| `src/components/` | Design system, motion, characters and illustrations |
| `supabase/` | Database schema and the AI gateway |
| `docs/` | Vision, design notes, setup guides and screenshots |

## Privacy

Quasar works without an account, analytics stay off unless you turn them on yourself, and your notes or explanations are only ever sent to the AI the moment you press an AI button, never before.
