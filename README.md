# quasar

### Learn it once. Remember it longer.

Quasar is a visual memory-learning app that gives every hard idea a place to live: a room, a character, a strange little story you can walk back through. It doesn't stop at showing you the idea once. It asks you to recall it without help, explain it in your own words, and then use it on a problem you haven't seen before. That's the whole loop, repeated across every subject in the app.

It's built with Expo and React Native, so the same codebase runs on iOS, Android and the web. The source is public here under the MIT license, and this is my entry for the RevenueCat Shipaton 2026 Next Gen Award. You can try it right now in the browser at quasar-memory-garden.reyaattri4.chatgpt.site, no account needed.

## What's inside

- **Cell City** is a six-episode biology story where you solve a blackout inside a living cell, exploring an illustrated atlas of districts and learning glycolysis, the citric acid cycle and ATP synthase with a cast of characters who react to every answer.
- **The memory toolkit** teaches memory palaces, number pegs, the Major System and other techniques through short illustrated conversations.
- **Courses** cover SAT vocabulary, biology, calculus, the digits of π and Korean, where a Hangul Lab and a sentence trail take you from building syllables to six everyday expressions.
- **Notes → Quiz** turns your own notes into highlighted study sections and flashcards first, then a quiz built on your device that comes back for spaced review.
- **Today** plans each session around what you're closest to forgetting, what's due and your exam date, fitted to 5, 15 or 30 minutes.
- **Teach-Back** hides the lesson while you explain it, **the Why Ladder** finds exactly where your understanding breaks, and **Case Lab** asks you to use the idea on a problem you haven't seen.
- **Error Memory** names the wrong answer you keep choosing and offers new angles until you get it right on your own.
- **Ready and the Memory Garden** measure recall, understanding and application separately, and each idea only blooms once you've answered it without help on two different days.
- **Quasar Plus** is currently open access, every AI feature below works for free during this launch window. Normally it sits behind a RevenueCat subscription that adds an AI tutor, AI quizzes from your notes or PDFs, personalized stories and fresh memory hooks, generated by Claude on the server.

Spaced review runs on FSRS (the same scheduling algorithm used by serious flashcard tools), answers given with a hint never count as mastered, and progress stays on your device unless you choose to back it up.

## Product vision

Quasar turns what a student is learning into a connected, personal memory universe: explore it through illustrated stories and walkable worlds, teach the ideas back, apply them to unfamiliar problems, and come back at exactly the points where understanding breaks. It's built around six pillars, each answering one question a student actually asks:

| Pillar | The student's question | What it does |
| --- | --- | --- |
| **Today** | What should I study, and why? | A rule-based planner ranks tasks by a priority formula, fits them to 5, 15 or 30 minutes, respects prerequisites, takes an exam date into account, and explains every pick. Recovery Mode takes over after a few days away with a small, review-first plan instead of a guilt-inducing backlog. |
| **Memory Worlds** | How do I make this unforgettable? | *The Secrets of Cell City*, a six-episode story world with six recurring characters, rebuild-from-memory games and fading cues, plus walkable dojo, desert and neon palaces and illustrated SAT, calculus, Korean and π courses. |
| **Teach-Back** | Can I explain it without help? | The lesson hides while you write or speak an explanation. Quasar checks it against authored key ideas on-device, asks a *why* question about the first missing one instead of revealing it, and Quasar Plus adds AI tutor feedback that quotes your own words back to you. |
| **Case Lab** | Can I use it to solve a problem? | Original two-attempt field cases per lesson, logged and rescheduled by Today until solved. The Why Ladder's final rung is also an unfamiliar application question. |
| **Memory Debugger** | Why do I keep getting this wrong? | Error Memory surfaces any concept missed twice, names the exact wrong answer you keep choosing next to what's true, offers alternative explanations, and only resolves after a later correct, unaided answer. Quasar Plus writes a self-repairing mnemonic aimed at that exact misconception. |
| **Ready** | What can I genuinely remember and use? | Separate meters for factual recall, conceptual understanding and unfamiliar problem-solving, computed only from your own answers. The Memory Garden shows every concept as a plant that blooms only after unaided recall on two different days. |

Today's priority formula: `P = 100 × (0.25·K + 0.25·R + 0.20·E + 0.20·I + 0.10·U)`, where K is the knowledge gap, R is review urgency from FSRS, E is exam proximity, I is authored importance and U is prerequisite value. One slot is always reserved for a due review, no more than two tasks of the same type appear in one plan, and every task shows the plain-language reason it was chosen. Implementation is in `src/lib/planner.ts`, tested in `tests/learning.test.ts`.

A few design principles run through all of it: accuracy before memorability, since an inaccurate mnemonic just makes misinformation memorable; honest measurement, so a hinted answer never counts as mastered and empty states say "not tested yet" instead of inventing a number; independence over dependence, so hints come as questions before answers; and speed, since reviews and plans are computed on the device and never wait on a network.

## Design notes

The visual language is warm paper, forest green, sage and one yellow accent, tokens live in `src/components/ui.tsx` with one type scale used everywhere, so it reads like a well-made notebook rather than a dashboard. Every illustration shows the specific object or relationship you need to remember, not a generic mascot, and different subjects get different styles on purpose: ink cartoons for SAT, gouache for biology, pixel worlds for memory palaces. Buttons are drawn in SVG with stepped pixel corners and a hard shadow they sink into when pressed, so the app feels a little like a game.

A few screens worth calling out specifically:

- **The landing screen** shows no feature list. One painting, a notebook whose pages grow into a path through the three memory worlds, fades onto the dotted paper with no frame, and no account is needed to start.
- **Cell City's six characters** are each drawn in a different style chosen to match their role, a hand-painted mayor, an ink-sketch archivist, pixel-art builders, and every one of them reacts to your answer in their own voice. The real biology is always stated before the city metaphor.
- **Today** lives on the Review tab, where studying actually happens: choosing 5, 15 or 30 minutes rebuilds the plan instantly, and after a break the card says plainly how long it's been and that nothing is lost.
- **Error Memory** shows your own wrong answer in red quotation marks directly above what's true, because seeing your own words back is more specific, and more motivating, than a generic "review this."
- **The Why Ladder** doesn't report a score. It reports exactly where your understanding broke, because that's what the next lesson needs to know.
- **The Memory Garden** has eighteen hand-drawn plants that never wither; a concept in Error Memory gets a small blue drop, a request for care rather than a penalty.
- **The Hangul Lab** treats every Korean syllable as a little building, with colour-coded slots showing exactly how each block stacks, teaching Hangul's real heaven-earth-person design before any memory cue.

Motion runs on Reanimated and Moti so it's native on iOS and Android and still works on the web, every component checks for reduced-motion and renders at rest when it's on, and every interactive element has a role, a label and a 44pt hit target.

## AI architecture

Quasar's AI features belong to Quasar Plus. Four things together decide whether a feature runs and what comes back: the learner's signed-in account, a RevenueCat entitlement (or the temporary open-access flag below), a daily quota, and a validated call to Claude. The core learning loop never depends on AI, and every AI feature has an on-device path that works without it.

```
Expo app (web · iOS · Android)
  Teach-Back · Notes → Quiz · Story · Error Memory
        │  src/lib/ai.ts → callAI(task, input)
        ▼
  POST /functions/v1/ai  (Bearer JWT)
        │
  Supabase Edge Function "ai"
   1. verify the Supabase JWT                       → Postgres
   2. is quasar_pro active? (server-side, never the client) → RevenueCat
   3. consume_ai_quota(user, task)                  → Postgres
   4. call Claude with a JSON schema, per-task effort, a timeout → Claude (official Anthropic SDK)
   5. validate the output before it reaches the learner
   6. log task · model · tokens                     → Postgres (ai_requests)
```

| Task | Feature | Output | What the server checks | Per day |
| --- | --- | --- | --- | --- |
| `tutor` | Teach-Back → *Ask the AI tutor* | coverage of each key idea with quoted evidence, wrong claims, feedback, one follow-up question | only a literal match counts as covered; advice only, the on-device check still decides mastery | 30 |
| `quiz` | Notes → Quiz → *Make an AI quiz* | 8–12 questions with explanation and source quote | four distinct choices, a valid answer index, and source grounding: a question whose quote isn't in your notes is dropped | 5 |
| `story` | *Make this story personal* | a 60–100-word mnemonic, optional picture | fact text comes from the database, never the client; only known profile fields are used | 10 |
| `hook` | Error Memory → *Write me a new memory hook* | a new hook aimed at the exact misconception, plus why it helps | must state the correct idea in words; saved beside the old cue, never replaces it automatically | 15 |

Everything a student writes (explanations, notes, profile fields) is sent as data, and the system prompt tells the model never to follow instructions inside it. Right now, Quasar Plus is running in an open-access mode for the launch window: a server secret called `AI_OPEN_ACCESS` lets the gateway skip the RevenueCat check so every signed-in user can use the AI features immediately, without needing a live subscription connected yet. Turning it off returns to the normal `quasar_pro` entitlement check. The model defaults to `claude-opus-5`, set through the official Anthropic SDK. More detail, including how to connect real keys, lives in `docs/AI-ARCHITECTURE.md` and `docs/GO-LIVE.md`.

## Run it

You'll need Node.js 22 or newer. The lessons, artwork and learning loop all work with no keys and no account.

```bash
git clone https://github.com/reyaattri/Quasar.git
cd Quasar
npm ci
npm run web
```

`npm start` opens the same app in Expo for iOS and Android. Setting up the optional services, Supabase, RevenueCat and Anthropic, is covered in `docs/SETUP.md`.

## Tests

```bash
npm run typecheck
npm test
npm run test:e2e
```

The unit tests cover the planner, spaced review, Error Memory, the notes quiz, Cell City, Hangul and the database rules. The browser tests walk through the app's main flows at phone size.

## Privacy

Quasar works without an account, analytics stay off unless you turn them on yourself, and your notes or explanations are only ever sent to the AI the moment you press an AI button, never before.
