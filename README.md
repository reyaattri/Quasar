### Learn it once. Remember it longer.

[Live demo](https://quasar-memory-garden.reyaattri4.chatgpt.site/) · [Product vision](docs/PRODUCT-VISION.md) · [Design narrative](docs/DESIGN-NARRATIVE.md) · [AI architecture](docs/AI-ARCHITECTURE.md) · [Demo script](docs/DEMO.md)

Quasar is a visual memory-learning app that gives every hard idea a place to live (a room, a character, a strange little story) and then asks you to recall it, explain it and use it without help. It's built with Expo and React Native for iOS, Android and the web, it's open source under the MIT license, and it's my entry for the **RevenueCat Shipaton 2026 Next Gen Award**.

## What's inside

- **Cell City** is a six-episode biology story where you solve a blackout inside a living cell, exploring an illustrated atlas of districts and learning glycolysis, the citric acid cycle and ATP synthase with a cast of characters who react to every answer.
- **The memory toolkit** teaches memory palaces, number pegs, the Major System and other techniques through short illustrated conversations.
- **Courses** cover SAT vocabulary, biology, calculus, the digits of π and Korean, where a Hangul Lab and a sentence trail take you from building syllables to six everyday expressions.
- **Notes → Quiz** turns your own notes into highlighted study sections and flashcards first, then a quiz built on your device that comes back for spaced review.
- **Today** plans each session around what you're closest to forgetting, what's due and your exam date, fitted to 5, 15 or 30 minutes.
- **Teach-Back** hides the lesson while you explain it, **the Why Ladder** finds exactly where your understanding breaks, and **Case Lab** asks you to use the idea on a problem you haven't seen.
- **Error Memory** names the wrong answer you keep choosing and offers new angles until you get it right on your own.
- **Ready and the Memory Garden** measure recall, understanding and application separately, and each idea only blooms once you've answered it without help on two different days.
- **Quasar Plus** is a RevenueCat subscription that adds an AI tutor, AI quizzes from your notes or PDFs, personalized stories and fresh memory hooks, generated by Claude on the server.

Spaced review runs on [FSRS](https://github.com/open-spaced-repetition/ts-fsrs), answers given with a hint never count as mastered, and progress stays on your device unless you choose to back it up.

## Run it

Use Node.js 22 or newer. The lessons, artwork and learning loop need no keys.

```bash
git clone https://github.com/reyaattri/Quasar.git
cd Quasar
npm ci
npm run web
```

`npm start` opens Expo for iOS and Android. Optional services (Supabase, RevenueCat, Anthropic) are set up in [docs/SETUP.md](docs/SETUP.md).

## Tests

```bash
npm run typecheck
npm test
npm run test:e2e
```

The unit tests cover the planner, spaced review, Error Memory, the notes quiz, Cell City, Hangul and the database rules, and the browser tests walk through the main flows at phone size.

## Project structure

| Path | What's there |
| --- | --- |
| `App.tsx` | App shell, onboarding, navigation and purchases |
| `src/features/` | Cell City, the courses, Notes → Quiz, Teach-Back, Why Ladder, Case Lab, Today, Error Memory, Ready and the Memory Garden |
| `src/lib/` | Progress, spaced review, the planner and the AI client |
| `src/data/` | Lesson content, Cell City episodes and memory cues |
| `src/components/` | Design system, motion, characters and illustrations |
| `supabase/` | Database schema and the AI gateway |
| `docs/` | Vision, design notes, setup guides and screenshots |

## Privacy

Quasar works without an account, analytics are off unless you turn them on, and your notes or explanations are only sent to the AI when you press an AI button.
