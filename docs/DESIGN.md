# Quasar design decisions

User messages take precedence over the original brief. The product is named Quasar. It remains an Expo mobile app, with an optional browser preview of the same React Native source.

The final user-selected default is the exact watercolor computing illustration attached in the conversation. It is stored unchanged at assets/cs-storybook.png. The SAT scene matches it. Doodle is an optional alternate rendering requested earlier; neither switching nor generating a variant changes the default file.

The shell uses warm paper, a subtle dot grid, dark green type, sage panels and yellow accents; hand-drawn SVG icons; restrained press feedback; mobile bottom navigation and a wider-screen sidebar. Misfits Market is a mood reference, not copied branding. Sketchy is a learning-interaction reference: memorable symbols, stories, recall, and application. All lesson prose is original.

Exactly two scenes, six hotspots each. Fixed normalized positions keep the route stable between styles. The hotspot list provides a readable, accessible alternative to small objects. Mnemonic details focus on one cue. Correct recall marks current mastery; later failure clears current mastery while preserving review history.

Application questions require writing before showing an example. Keyword hints only point out missing terms; students check reasoning themselves. They do not award an unearned automated correctness score.

The brief’s sample schema placed mastery on shared hotspots. This implementation correctly keeps mastery in per-user state. RevenueCat remains the source of subscription entitlement; a client-editable database field never unlocks the paid generation endpoint.
