# Explore and room update

Explore now contains Fun & Flex and the existing memory toolkit. Repeated subject panels are removed. The Home subject thumbnail uses the wizard comic in a 112-pixel-high area.

## Practice games

- Cards: six, twelve or all 52 shuffled cards. Each rank has one fixed peg; suits supply a distinct costume. Each card is assigned a unique position among thirteen rooms with four landmarks per room. Study cards individually, then recall the exact sequence. This is a beginner one-image-per-card system, not a full PAO trainer.
- Names: six original, equal-size SVG portraits. Accessory-linked mnemonic stories, individual introductions, shuffled face recall and original meeting-position recall. Artwork and name associations are fictional.
- Pairs: six linked pairs placed at route landmarks, followed by cued recall.
- Passphrase: a fixed fictional six-word example demonstrates a story chain. This is not a credential generator. Inputs are not sent or saved by this feature. Do not use the public example as a real credential.

Game rounds currently remain in component state; leaving Explore or reloading starts a fresh round. Palace routes continue to use the app's saved progress.

## Rooms

Original illustrated world maps fill the available game viewport. Each of six stops opens its own room; Back returns to the same map stop. Neon stop 2 is an arcade and stop 3 is a greenhouse. A visible object-mounted cue is supplied without requiring user input. Optional personal hooks and anchor changes are retained. Hidden recall conceals the scene, and the final challenge checks all memories in route order.

Japanese room art is a generated six-panel atlas (`assets/rooms-dojo.png`). The other rooms use original SVG sets and the previously approved conservatory image. The image-generation service reached its usage limit after the Japanese atlas; no generated Egyptian or neon room atlas is claimed. Custom shopping routes with seven/eight items reuse room layouts for the additional terrace/fountain locations.

## Method references

- [Art of Memory: introductory methods](https://artofmemory.com/resources/Learn_the_Art_of_Memory.pdf): fixed card associations and ordered location routes.
- [Art of Memory: names and faces](https://artofmemory.com/wiki/Memorizing_Names_and_Faces/): name images, distinctive features and locations.
- [EFF: creating strong passwords](https://ssd.eff.org/module/creating-strong-passwords): secure generation is separate from memorability. The app only teaches recall with a fictional example.

These methods informed the activities; no learning-outcome guarantee is implied. Card pegs, portraits and stories were authored for Quasar.
