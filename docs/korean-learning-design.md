# Korean neighbourhood

This is an introductory course, not a complete Korean curriculum. The existing Hangul story, drawing recall, audio, syllable builder and sound contrasts lead into six practical expressions: greeting, student introduction, water, coffee, having a book and thanking someone.

## Learning sequence

Each sentence has a short memory scene, a plain-language grammar explanation, Korean pronunciation playback, removable word tiles, then a written recall prompt with the Korean answer hidden. Correct and incorrect recall attempts use the existing spaced-review scheduler under `ko-sentence-*` IDs. These attempts do not contribute to biology readiness. Romanization appears only while learning; it is a listening aid, not the assessment answer.

The memory scenes are original Quasar stories. They help retrieve an expression but do not replace Korean pronunciation or grammar. Learners can review any stop, and due sentences appear on the sentence-trail home screen.
