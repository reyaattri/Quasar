# Demo

## Two-minute script (for the Shipaton video)

Record at phone size. If it's the web build rather than a phone, say so in the description.

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:12 | The landing: the notebook painting, pick a subject, tap the pixel button | "Most study apps show you the same explanation again. Quasar gives every idea a place to live." |
| 0:12–0:40 | Explore → Cell City → Episode 1: the real biology, a character speaking, the rebuild game, one clue answered wrong so the host reacts | "In Cell City I learn how cells make energy by solving a blackout. The real science comes first, then the story that makes it stick." |
| 0:40–0:55 | Notes → Quiz: paste notes, read the highlighted sections, flip a flashcard, answer a question | "I can bring my own notes. I study them first, then Quasar quizzes me, and every question comes back later." |
| 0:55–1:10 | Review: Today's plan, switch 15 → 30 minutes, read one task's reason | "Today picks what I'm about to forget and tells me why." |
| 1:10–1:30 | An Error Memory card ("You keep choosing…"), then Explain it back and the guiding question | "Miss something twice and Quasar names the exact mistake. When I explain it back, it asks a question instead of handing me the answer." |
| 1:30–1:48 | Ready: the three meters, then the Memory Garden | "Recall, understanding and application are measured separately, and an idea only blooms when I've got it right on my own." |
| 1:48–2:00 | The Quasar Plus screen | "The lessons are free. Quasar Plus adds an AI tutor and AI quizzes through RevenueCat." Only show a purchase if a sandbox purchase has actually been completed. |
