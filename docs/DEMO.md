# Quasar walkthrough

The silent recording in quasar-demo.webm shows a fresh demonstration profile, the ink-cartoon vocabulary deck, the walkable dojo and doll cue, a custom shopping list, and medical foundation recall. The recording uses the web build at a phone viewport. It is not an Android emulator recording.

Regenerate with PLAYWRIGHT_BROWSERS_PATH configured for Playwright FFmpeg, then run node scripts/record-demo.cjs while Metro runs on port 8081.
